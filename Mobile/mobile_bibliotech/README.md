# Bibliotech Mobile

Aplicativo mobile do projeto Bibliotech, desenvolvido em Flutter

## Sobre o projeto

O Bibliotech é um sistema para gerenciamento e consulta de livros. A versão mobile permite que o usuário navegue pelo catálogo, consulte livros, realize empréstimos e acompanhe seus livros.

## Tecnologias utilizadas

* Flutter
* Dart
* Material Design

## Funcionalidades

* Login de usuário
* Página inicial
* Catálogo de livros
* Destaques
* Busca por gêneros
* Empréstimo de livros
* Área "Meus Livros"
* Navegação entre telas
* Persistência do login e dos livros emprestados

## Como executar

1. Tenha o Flutter instalado.
2. Abra a pasta do projeto.
3. Execute:

```bash
flutter pub get
```

4. Inicie o aplicativo:

```bash
flutter run
```

## Estrutura

O projeto possui as principais telas organizadas na pasta `lib/telas`, além dos arquivos responsáveis pela configuração e funcionamento do aplicativo.
