##  Sobre o Projeto
O projeto Bibliotech foi desenvolvido com o objetivo de modernizar e facilitar o acesso aos serviços de bibliotecas, utilizando tecnologia para tornar a experiência dos usuários mais prática e eficiente.

A proposta envolve a criação de um sistema digital que permite:
-  Organização de acervos
-  Consulta de livros
-  Acesso a conteúdos online
-  Integração com plataformas digitais

---

- Backend: Node.js
