# Bibliotech Front-end

Front-end do projeto Bibliotech, desenvolvido para apresentar e gerenciar as funcionalidades do sistema de biblioteca.

## Sobre o projeto

O Bibliotech é um sistema de biblioteca que permite consultar livros, visualizar informações do catálogo e realizar operações relacionadas aos empréstimos.

## Tecnologias utilizadas

* HTML
* CSS
* JavaScript

## Funcionalidades

* Página inicial
* Catálogo de livros
* Consulta de livros
* Destaques
* Gêneros
* Login
* Cadastro de usuário
* Empréstimo de livros
* Área de livros do usuário
* Integração com o back-end

## Como executar

1. Clone o repositório.
2. Entre na pasta do Front-end.
3. Abra o projeto no Visual Studio Code.
4. Execute o projeto utilizando o ambiente configurado para o desenvolvimento.

## Estrutura

Os arquivos do front-end são organizados em páginas, estilos e scripts responsáveis pela interface e pelas funcionalidades do sistema.
